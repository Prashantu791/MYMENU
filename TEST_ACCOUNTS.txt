3. DATABASE SEPARATE TABLE INFO ('mess_owners')
--------------------------------------------------------------------------------
Jab bhi koi Mess Owner register karta hai, unka data MySQL me dedicated table
'mess_owners' me store hota hai:

Table Name: mess_owners
Columns:
- id            : Auto-increment primary key
- user_id       : Link to users table (ID)
- owner_name    : Full Name of the Owner
- email         : Registered Email
- phone         : Contact Mobile Number
- mess_id       : Link to messes table (ID)
- mess_name     : Name of the Mess
- mess_address  : Location / Address
- created_at    : Registration timestamp

MySQL Workbench me check karne ke liye query:
    USE mymenu;
    SELECT * FROM mess_owners;

Direct REST API se check karne ke liye:
    GET http://localhost:8080/api/auth/mess-owners

4. HOW TO RUN SERVER
--------------------------------------------------------------------------------
Option 1: Double-click 'START_SERVER.bat' in the project folder.
Option 2: In STS (Spring Tools for Eclipse), right-click MyMenuApplication.java -> Run As -> Spring Boot App.

Port 8080 agar busy ho to:
- Double-click 'FREE_PORT_8080.bat' to immediately free port 8080.
